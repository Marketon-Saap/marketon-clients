## Deploy

GitHub Pages sirve el root de este repo desde `main`. Cada cliente vive en su propia subcarpeta bajo `clients/`.

### Ramas por cliente

Cada cliente tiene su rama de desarrollo:
- `karbot` — desarrollo landing Karbot
- (agregar según se sumen)

Los cambios se hacen en la rama del cliente, se validan localmente, y se mergean a `main` para que Pages los despliegue.
